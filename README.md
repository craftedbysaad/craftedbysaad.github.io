# Saad — Web & App Designer

Personal portfolio of Muhammad Saad, live at **https://craftedbysaad.github.io**.

When the page opens, a crew of AI agent cursors builds it layer by layer, then the page goes live.
Hand-built with HTML, CSS and JavaScript — no framework, no template.

Fonts: Big Shoulders, Instrument Sans, JetBrains Mono, Nothing You Could Do (all SIL Open Font License, see `assets/fonts`).
